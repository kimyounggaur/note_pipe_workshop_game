## 부록 B. 잠금 정답표

전부 스파이크의 엔진이 씨앗에서 만든 값이다 [계산]. 프롬프트 가이드의 Step 0에 그대로 넣는다. 제품의 엔진으로 다시 만들었을 때 글자까지 같아야 한다(JT1의 4번 작업).

### B.6 틈, 소리의 끝, 시간 값

**틈.** `min(1/4박, 길이 ÷ 2)`.

| 점2분음표 3박 | ¼박 | 2¾박 | 2.75초 |

| 8분음표 ½박 | ¼박 | ¼박 | 0.25초 |

**소리의 끝.** 6.2절의 값이다.

| 종류 | 언제 | 게인 |
|---|---|---|
| 끊김 `cut` | 뒤가 뗌이거나 마지막 소리 | 울리는 길이의 끝 40ms 전부터 줄어 끝에서 꺼진다 |
| 겹침 `over` | 뒤가 이음이고 높이가 다르다 | 끝에서 줄기 시작해 30ms 뒤에 꺼진다 |
| 잠깐 꺼짐 `dip` | 뒤가 이음이고 높이가 같다 | 끝 70ms 전부터 줄어 끝 12ms 전에 꺼진다 |
| 시작 | 새로 시작 / 이어서 시작 | 18ms / 30ms에 걸쳐 최고값 0.24까지 |

**시간 값.**

| 이름 | 값 |
|---|---|
| 빠르기 | ♩=60. 느리게 ♩=50 |
| 예약의 앞섬 | 누른 순간 + 0.12초 |
| 준비 박 | 그날 첫 밸브 4, 그 뒤 2. 시운전과 듣기에는 없다 |
| 재생의 끝 | 본 구간의 끝 + 0.3초 |
| 누른 채 판정의 창 | 이음매 앞뒤 1/16박(♩=60에서 62.5ms, ♩=50에서 75ms) |
| 뗐다 누름 판정의 창 | 이음매 앞뒤 1/4박(250ms, 300ms) |
| 재시작 보호 | 끝난 뒤 0.6초 |

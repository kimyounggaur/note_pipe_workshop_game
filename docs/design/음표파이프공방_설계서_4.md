## 10. 단계별 실행 계획 JT0~JT9

### 10.0 공통 규칙

1. 단계를 시작할 때 `index.html#test`를 열어 지금까지의 검사가 전부 통과함을 확인한다.
2. **검사를 조용히 고치지 않는다.** 기대값이 틀렸다고 판단하면 부록 B와 대조하고, 바꾼 이유를 결정 기록에 적는다.
3. 화면을 건드린 단계는 320×545, 320×568, 360×640, 390×844에서 스크롤과 잘림을 본다.
4. 부록 C의 코드는 고쳐 쓰지 않고 옮긴다. 고쳐야 하면 무엇을 왜 고쳤는지 게이트 보고에 적는다.
5. 단계가 끝나면 아래 블록을 `docs/joint-gate-report.md`에 더한다. 돌리지 못한 항목은 `NOT_RUN`으로 적는다.

```yaml
GATE_REPORT:
  gate: GJT4
  status: PASS            # 또는 PARTIAL / FAIL
  tests: { TH: 0/17, IN: 0/3, CN: 0/4, JD: 0/8, GN: 0/14, AU: 0/9, ST: 0/6, SV: 0/4, CT: 0/3 }
  viewports: [320x545, 320x568, 360x640, 390x844]
  external_requests: 0
  file_bytes: 0
  device_check: NOT_RUN   # 실기기로 확인했으면 기종과 날짜
  listening_check: NOT_RUN  # 세 이음매를 귀로 가렸으면 기종과 날짜
  open_issues: []
```

### 11.2 소리를 검사하는 법

소리는 들어 보지 않고도 검사할 수 있는 부분이 있다. 페이지가 뜨기 전에 `createOscillator`를 감싸 주파수, 예약 시각, 취소 여부를 기록한다(부록 C.9). 잡음 소리는 `burst`를 감싸 종류를 기록한다. 진폭은 `OfflineAudioContext`에 같은 `pipeTone`으로 렌더해 2ms마다 잰다. 이 문서의 소리 항목을 모두 이 방식으로 확인했다.

이 방식으로 알 수 없는 것이 이 타이틀의 가장 큰 위험이다. 실제 음량과 음색, 폰 스피커에서 44ms의 꺼짐이 들리는가, 기기의 재생 허용, 출력 지연. JT3의 6번 작업이 그것을 듣는 자리다.

- 5.2절의 공식, 4.3절과 4.5절의 원인 표, 4.6절의 밸브 표, 6.3절의 예약 규칙, 4.8절의 흐름 그림, 8.1절의 치수 표.
- 10.0절의 공통 규칙.

**작업 전에 답하게 할 질문.**

1. 도 도 레 미에서 곡선이 두 도만 이으면 그 곡선은 무엇인가? 같은 곡선이 미까지 덮으면 두 도 사이는 어떻게 연주하는가? (붙임줄이고 뒤의 도를 다시 내지 않는다. 덮으면 이음줄이고 두 도 사이는 이음이라 다시 낸다. 이름은 양 끝 음에서 읽는다)
2. 붙임 하나에 방울은 몇 개 줄어드는가? 이음은? (하나. 이음은 줄이지 않는다. 방울 수 = 음표 수 − 붙임 수)
3. 높이가 다른 이음매에 붙이기를 쓰면 어떻게 되는가? (거절한다. 상태는 그대로이고 까닭을 말한다. 틀린 것으로 세지 않는다)
4. 곡선 객체에 `type: "tie"`를 저장하면 안 되는 이유는? (같은 음이 낀 이음줄에서 어긋난다. 악보처럼 양 끝 음에서 읽어야 한다. 두 곡선의 선도 같아야 한다)
5. 2분음표와 8분음표를 붙인 길이를 2.5로 두면 안 되는 이유는? (합이 정확해야 하고 "음표 하나로 적을 수 있는가"를 분수로 가린다. 소수는 화면 좌표와 소리 시각에서만 쓴다)
6. 뗌의 틈은 얼마인가? 8분음표에서는? (1/4박. 짧은 소리는 길이의 절반까지만 비우므로 8분음표는 1/4박 울리고 1/4박 빈다)
7. 같은 음의 이음을 밸브에서 누른 채 지나면 어떻게 되는가? (한 곳 샘. 주파수가 그대로라 한 소리로 들린다. 짧게 뗐다 눌러야 한다)
8. 밸브가 "여러 곳 샘"이어도 다음 작업일이 열리는가? (열린다. 통과는 셈과 검수의 1차 정답으로만 정한다)
9. 둘째 음을 `setTimeout`으로 내면 안 되는 이유는? (박이 흔들리고 취소할 수 없다. 모든 음을 한 번에 예약하고 묶음으로 취소한다)
10. 물머리와 밸브 판정이 서로 다른 시계를 쓰면 어떻게 되는가? (보이는 물과 판정이 어긋난다. 둘 다 "지금 들리는 시각"을 쓴다)
11. 재생 도중 소리 시계가 멈추거나 화면을 떠나면 어떻게 하는가? (중단하고 준비 상태로 돌아가 사유를 말한다. "소리 켜기"를 보여 준다)
12. 의뢰 카드의 높이를 내용에 맡기면 어떻게 되는가? (소리 의뢰에서 카드가 커져 무대가 줄고 물길이 잘린다. 다섯 줄 가운데 넷은 고정이다)
13. 마감 의뢰에서 꺼지는 것은 무엇인가? (방울 그림과 판독 줄의 방울 수. 시운전 때 지나간 방울만 보인다)
14. 검수에서 틀린 곳이 둘이면 무엇을 표시하고 무엇을 말하는가? (둘 다 표시하고 원인은 하나만 말한다. 순서는 4.5절이다)

**단계 대응.** JT0~JT9를 프롬프트 묶음 하나씩으로 만든다. JT2, JT4, JT5, JT6은 작업 표의 줄마다 한 프롬프트로 나눈다. 각 프롬프트는 "선행 게이트 확인(`#test`) → 작업 → 검사 추가 → 네 화면 캡처 → 게이트 보고 블록" 순서를 따른다. 세션을 새로 열 때 붙일 복원 블록에는 R1~R15, 용어표, 지금 단계, 통과한 검사 수를 넣는다.

**문제 해결 씨앗.**

| 증상 | 원인 | 고침 |
|---|---|---|
| 같은 음이 낀 이음줄이 붙임으로 그려진다 | "같은 음이면 붙임줄" 분기 | 곡선은 양 끝 음에서 읽는다(R5, 5.2절) |
| 붙임줄과 이음줄의 색이나 굵기가 다르다 | 곡선에 종류를 저장하고 꾸몄다 | 같은 선 속성(E-02) |
| 방울 수가 판독 줄과 그림에서 다르다 | 따로 셌다 | `sounds()` 한 곳에서만 낸다(R6) |
| 도–레가 붙는다 | 거절이 없다 | `withJoint`의 결과를 본다(R4) |
| 2½박이 "2.5박"이나 "5/2박"으로 나온다 | 소수로 두었거나 글 함수를 거치지 않았다 | 분수 + `beatsKo` |
| 음표 머리와 토막이 어긋난다 | 설계도와 물길이 다른 폭을 쓴다 | 같은 `X(박)`(R1) |
| 소리 의뢰에서 물길이 1px 잘린다 | 의뢰 카드가 커졌다 | 줄 높이 고정, 치수는 위쪽 줄을 고친 뒤에 잰다(R10) |
| 단계가 바뀔 때마다 화면이 들썩인다 | 조작부 높이가 내용에 따라 바뀐다 | 104px 고정 |
| 물길을 가리면 아래가 올라온다 | 지웠다 | 보이지 않게만 한다(9.3절) |
| 빨리 누르면 음이 겹친다 | 앞선 예약을 취소하지 않았다 | 새 재생 전에 묶음 취소(R7) |
| 재생이 끝나지 않고 굳는다 | 소리 시계가 멈췄다 | 정지 감시와 중단(6.5절) |
| 화면을 떠났다 오면 "소리가 멈춰서"라고 나온다 | 사유를 나누지 않았다 | 사유별 문구(4.9절) |
| 아이폰에서 첫 누름에 소리가 없다 | 언락이 재생 단추에만 걸려 있다 | 전역 세 가지 + "소리 켜기" 표시 |
| 밸브가 끝나자마자 다시 시작된다 | 손을 뗄 때의 `click`, 키 떼기 | `swallow`, `keyHeld`, 끝난 뒤 0.6초 보호(부록 C.8) |
| Enter를 누르고 있으면 의뢰가 둘 넘어간다 | 키의 자동 반복 | 반복 `keydown`의 기본 동작을 막는다 |
| 기계 밸브를 누르면 키보드 초점이 사라진다 | `disabled`로 잠갔다 | `aria-disabled`와 처리기의 거름(R13) |
| [검수] 뒤에 Tab이 처음부터 돈다 | 누른 단추가 숨었다 | 단계가 바뀌면 초점을 옮긴다 |
| 듣는 도중 이음매를 누르면 듣기가 끊긴다 | 모든 재생을 멈췄다 | 의뢰 듣기는 배관 조작으로 끊지 않는다 |
| 같은 음의 이음을 누른 채 지나도 매끈이 나온다 | 이음을 전부 "누른 채"로 보았다 | `expectHeld`는 높이가 다를 때만 참이다 |
| 방울 숫자에 테두리가 생긴다 | 부품 클래스와 상태 클래스의 이름이 같다 | 부품 `coupler`, 상태 `rung` |
| 한글이 낱말 중간에서 줄바꿈된다 | 기본 줄바꿈 | `word-break: keep-all` |
| 좁은 화면에서 HUD가 넘친다 | 제목, 진행 점, 소리 켜기, 설정이 한 줄 | 소리 켜기가 보이는 동안 제목을 숨긴다. 이름은 86px 이내 |
| "도을", "솔와"가 나온다 | 조사를 고정했다 | `eul`, `wa` |
| 눕힌 폰에서 무대가 잘린다 | 높이가 545px 미만 | 안내와 "그래도 계속하기"(8.1절) |
| 0단에 "뗌" 칩이 보인다 | 도구가 없는 날에도 칩을 그렸다 | 도구가 없으면 칩을 숨긴다 |
